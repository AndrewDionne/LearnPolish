# A-00 — Learning experience and progression audit

**Date:** 2026-10-23. **Authority:** [execution roadmap](EXECUTION_ROADMAP.md), `V2_REBUILD_PLAN.md`, `v2/DEFERRED_PHYSICAL_TEST_ROADMAP.md`, root workflow and [issue #2](https://github.com/AndrewDionne/LearnPolish/issues/2). **Status: repository-backed source audit and delivery proposal, not implemented feature change, learner research, acoustic verification or native Polish content certification.** The separate complete catalogue mapping and three-course-phase gaps are in [CORE_CURRICULUM_GAP_PLAN.md](CORE_CURRICULUM_GAP_PLAN.md).

## Executive finding

V2 has working, secure, four-mode *activities*, a recent UX standard, local recall/review, private family engagement and optional next lessons. It does **not yet have a coherent core *course***. The current automatic successor is the next item in the old topic-based Fundamentals → Basic → Learning Library ordering. The Home Continue action resumes the last visited lesson—even a personal exercise—not the next core course unit. Progress counts “encountered” content, not demonstrated everyday conversational competence. Repetition is intelligently guarded, but no authored cross-mode unit objective or course pathway connects Listen → Speak → Read in a real-life situation. Curriculum reconstruction must precede implementation of a sophisticated progression engine.

**Critical distinction:** This is not a claim that current navigation, XP or audio is broken. Most existing deterministic UX, recovery, privacy and latency/race safeguards are already certified. The gaps are largely **curriculum architecture + progression semantics**.

## Constraints / high-confidence non-regressions

- All **26 existing V2 lessons, 482 items, 455 inherited original MP3s**; 5 sound contrast sets, 7 Fundamentals vocab sets, 7 Basic phrase sets, 6 Reading sets and one `speak_swietokrzyska` diagnostic must survive. Do not claim 26 *fully validated* units: source/topic mappings are editorial, language and audio not native-certified.
- Keep the original `numbers_1-20` as **one** source lesson with opt-in **1–10 / 11–20** practice batches, not 1–8/9–16 or automatic partitions.
- Preserve existing `personal_` stable IDs and audio-free imported JSON, local independent edits, maximum 100 personal lessons/150 items each, offline backup/restore and progress. Existing family contribution policy cannot be expanded to personal lessons.
- Keep 14 original questionable reference targets `practice_only`; do not use as scored Speak/Listen, no arbitrary unverified MP3.
- Playback 0.75×/0.85×/1×, optional English pronunciation guide OFF, word-coloured script hints and experimental composite only when genuine separate permission & provider gates are satisfied.
- **No completion gates based on Azure/Whisper blend, sound-unit colours or personal self-rating.** Avoid overclaiming course proficiency.
- No silent release, paid inference, SMS/email activation, cross-device local-data synchronization or real physical/mobile/native Polish sign-off.
