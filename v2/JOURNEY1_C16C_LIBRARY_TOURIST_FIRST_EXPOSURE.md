# C-16C — Original Library and Tourist first-listening source instruction

## Owner learning contract

Learners should be able to learn Polish without outside study. A later lesson must not assume unfamiliar vocabulary, sounds, inflections or grammar unless earlier lessons have taught them. If an independently opened source lesson or tourist scene contains unfamiliar material, introduce it **within that source lesson before comprehension** using the already recorded COMPLETE Polish item and original English. The original 26 source lessons, 482 items and 455 imported whole MP3s must remain unchanged. Spoken practice stays full-word/full-utterance audio → record → one overall score and colour-marked text where evidence permits → Try again/Next. No extra syllable playback, score/XP streams, mandatory proficiency locks or invented native-speaking signoff.

## Implemented in C-16C

**Original seven basic Library lessons**: 172 original basic source phrases were already inventoried in C-15, of which only 48 were in the C-16B actual guided sequence. In **independent Library Listen**, the learner now has a compact optional **“Learn these expressions first”** panel showing the exact Polish, English and full original source MP3, one real source item at a time, in the actual source-lesson order. The same 15 strictly anchored draft grammar cues previously prepared for the guided first-sentence phrases appear on the matching original Library lines, never on an unrelated line. The original meanings and audio are provided **before** multiple-choice Listen guessing; choosing to skip preserves normal direct practice for experienced users. Source ID/text/English/audio identity and non-protected reference status must all agree before showing an introduction. Sessions referencing protected `practice_only` recordings cannot be laundered into a new playable example.

**Tourist T01–T08 Listen scenes**: the scene can be entered independently; no claim that the learner completed the core route or any earlier tourist scene is made. Each original tourist **Listen** excerpt now receives the same matching pre-quiz teaching of the exact selected whole source utterances, their recorded audio and English meaning, with original C-15/C-16A source-specific draft reading dialogue explanations and C-16B sentence cues where actually applicable. T03's Numbers 1–10 excerpt uses the original full number recordings, with no attempt to split 1–20 into a new original lesson. The source intro is unavailable if any item, source identity, text, MP3 path, subset order or protected item status differs from the source. The original optional scene Read and Speak pathways, family XP, source item identities and resume cursor are unchanged.

**Speak remains deliberately compact**: existing `SpeakPanel` already displays the full Polish target and original English, offers the complete original reference recording before recording the learner, and refuses unavailable/protected reference audio; no duplicate tour or introductory panel is inserted ahead of the microphone UI. A file's existence is NOT evidence its audio is native-certified, and synthetic CI is NOT a physical microphone test.

## Explicit limitations / next C-16D

The new original source-backed introductory experience is not yet a fully reviewed, linear native Polish grammar course. **157** original basic expressions outside the 15 focused source-anchored grammar cues still need specific high-risk morphology/register/pronunciation editorial work where appropriate, regardless of whether they have an audio + meaning card. The 51 original recorded Read dialogue lines already have draft explanation notes. T01–T08 remain **source-backed optional exploration**, not a newly invented full two-way tourist conversation and not a new required stage. Source content rights, human native review, diagnostic Speak pronunciation calibration and real microphone checks remain [Issue #140](https://github.com/AndrewDionne/LearnPolish/issues/140). [Issue #156](https://github.com/AndrewDionne/LearnPolish/issues/156) stays open until every true dependency is adequately taught and reviewed.

**Recommended next development step**: a prioritized linguistic *substance* pass over original basic source phrases, starting with new pronouns, verb forms, noun declensions, formal address and question constructions in the 124 Library-only basic rows. Add concise, exact-source draft explanations where they genuinely improve the learner's understanding; then obtain native Polish speaker review before asserting correctness. Audit each tourist scenario for missing natural speaker replies and recorded coaching. Continue to preserve file integrity and all four final-head GitHub CI checks before merging.
