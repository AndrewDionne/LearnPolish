# Path to Polish V3 — native learning experience

**Decision date:** 2026-11-11. **Authority:** owner iPhone screenshots and review.
**Status:** approved target, implemented in tranches. GitHub is continuity.
The original V2 learning IDs, recorded Polish and private Neon/Render family data are preserved.

## One journey, three exercise types

- **Speak:** the unified first-contact word/phrase experience. Hear the original audio; see the Polish word, English meaning and optional guide; record/replay; eventually an independently verified overall score and syllable-coloured word (coloured text, not boxes). Never show fabricated phonetic success or provider scores before calibration and explicit consent.
- **Learn:** memory and recall. Polish audio/word -> choose correct English meaning, followed by spaced review. An optional flip-card alternative is ungraded until genuine retrieval is recorded.
- **Listen:** a short authentic dialogue/connected utterance followed by genuine meaning/context comprehension questions. A single phrase with Reveal Meaning does not qualify as a complete comprehension exercise.

The course should choose when to assign each exercise. Learners should not have to switch modes inside a single Dzień dobry card. Intro -> recall -> pronunciation -> reinforcement -> dialogue must follow authored prerequisites and reuse real source IDs. 16 guided first-word/grammar groups and 19 core Journey 1 placements currently overlap; review the 74 written first-use forms before claiming a single certified gapless path.

## Tab responsibilities

**Home:** real local attempts, XP, due reviews, recent activity, started sessions, one Continue in Practice action, and optional team/family status. Never present an invented team score; group totals are server-authoritative and require voluntary authenticated connection.

**Library:** browser for concise source-derived learning journeys, each up to four existing lessons, with number of lessons, started/practised counts, self-rated recall (the current legacy Got it / Needs practice evidence), clearly labelled; objective matching accuracy only after Learn quizzes are implemented. Keep Sound Lab, scenarios, Polish names and other appropriate material clearly labelled Extras. Selecting a lesson switches to Practice.

**Practice:** owns all active exercises, multiple individually paused/resumed lessons and foundations groups, and due reviews. No credit for navigation, Play or Skip. Separate persisted cursors must survive force-quit and rereading Library.

**Expedition:** retain genuine regional XP and map. Later add source-reviewed cities, mountain ranges, national parks, cultural highlights and coherent UX for regional goals.

**Progress:** detailed individual results, local backups/restores and optional family/account settings, not the primary starting point for learning.
