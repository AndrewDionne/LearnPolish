# Path to Polish V3 — native learning experience

**Decision date:** 2026-11-11. **Authority:** owner iPhone screenshots and review.
**Status:** approved target, implemented in tranches. GitHub is continuity.
The original V2 learning IDs, recorded Polish and private Neon/Render family data are preserved.

## One journey, three exercise types

- **Speak:** the unified first-contact word/phrase experience. Hear the original audio; see the Polish word, English meaning and optional guide; record/replay; eventually an independently verified overall score and syllable-coloured word (coloured text, not boxes). Never show fabricated phonetic success or provider scores before calibration and explicit consent.
- **Learn:** memory and recall. Polish audio/word -> choose correct English meaning, followed by spaced review. An optional flip-card alternative is ungraded until genuine retrieval is recorded.
- **Listen:** a short authentic dialogue/connected utterance followed by genuine meaning/context comprehension questions. A single phrase with Reveal Meaning does not qualify as a complete comprehension exercise.

The course should choose when to assign each exercise. Learners should not have to switch modes inside a single Dzień dobry card. Intro -> recall -> pronunciation -> reinforcement -> dialogue must follow authored prerequisites and reuse real source IDs. 16 guided first-word/grammar groups and 19 core Journey 1 placements currently overlap; review the 74 written first-use forms before claiming a single certified gapless path.

## Tab responsibilities

**Home:** real local attempts, XP, due reviews, recent activity, started sessions, one Continue in Practice action, and optional team/family status. Never present an invented team score; group totals are server-authoritative and require voluntary authenticated connection.

**Library:** browser for concise source-derived learning journeys, each up to four existing lessons, with number of lessons, started/practised counts, self-rated recall (the current legacy Got it / Needs practice evidence), clearly labelled; objective matching accuracy only after Learn quizzes are implemented. Keep Sound Lab, scenarios, Polish names and other appropriate material clearly labelled Extras. Selecting a lesson switches to Practice.

**Practice:** owns all active exercises, multiple individually paused/resumed lessons and foundations groups, and due reviews. No credit for navigation, Play or Skip. Separate persisted cursors must survive force-quit and rereading Library.

**Expedition:** retain genuine regional XP and map. Later add source-reviewed cities, mountain ranges, national parks, cultural highlights and coherent UX for regional goals.

**Progress:** detailed individual results, local backups/restores and optional family/account settings, not the primary starting point for learning.

## Delivery and acceptance

**UX-01 — current tranche:** real Home dashboard; Library source-mapped collections; route starts to Practice; independent per-set local resume, honest progress/recall and tests. No source or service rewrites.

**UX-02A — implemented in draft:** Remove the four-way per-card picker. Original source items follow an explicit, deterministic early cadence: first lesson phrase uses Speak (audio, Polish, original English meaning, local record/replay), and later vocabulary steps alternate with Learn (3 source-meaning multiple-choice answers). Sound-contrast sets stay Speak; unscripted reading remains Read without being passed off as a dialogue. Learn offers optional flip-card study that earns no XP or matching score; after revealing the answer, the learner cannot submit a graded matching answer for that same attempt. **Listen** is now a dedicated authored-exchange activity for the 3 existing V2 pilot micro-dialogues (2 greeting, 1 grocery), hearing authentic original turns then answering the exact authored contextual question. Turns are played in order by tapping each original MP3; seamless whole-dialogue playback is not yet implemented.

Every objective Learn or dialogue answer has a backward-compatible, source-validated evidence tag in the local practice journal, with matching accuracy separate from legacy self-rated "Got it". Event projection, local archive/restore validation and cross-device candidate replay retain that distinction. The original source IDs, pronunciation consent and family backend are unchanged.

**UX-02B — implemented in draft:** All 16 original foundation groups now have an introduction pass with **Speak** (source MP3, original English meaning, grammar cue when applicable, local record/replay and optional consented pronunciation estimation). Where a step contains at least three distinct source English meanings, a second **Learn** recap uses exactly three original meanings from the same group; a genuine answer is required for objective matching evidence. The two-item "Yes and no" step does not fabricate a third distractor. Legacy guided Learn self-ratings count as prior participation but are never retroactively called objective answers. Both guided activity phases and their item cursors resume from compatible optional local fields; revealing a translation, playback, browsing or Skip awards no practice. Independent source references are shared, not duplicated with fabricated lesson IDs.

**UX-02C — next:** Strengthen dialogue playback with a seamless queue, and replace the deterministic provisional exercise cadence with a fully editorially authored, prerequisite-audited mixed-exercise path. The Listen catalog still contains only three source-authored dialogues. No invented phonetic or syllable scores.

**UX-03A — native single Journey 1 path implemented in draft:** one source-validated, browseable sequence with 8 named chapters and 35 existing activities (16 guided + all 19 original Journey 1 lessons). The five existing sound-contrast lessons move earlier, after first words. The 16 guided groups keep their original prerequisite order; the 19 core lesson IDs remain exactly once, although the previous source *pilot* placement order is deliberately revised at the first sound-to-conversation transition. The longest source dialogues and practical situations follow basic vocabulary and grammar. No new Polish, recorded audio, lesson IDs, artificial grades or account data. Home and Practice choose the first unfinished activity from the same path. Library exposes Journey 1 as a browsable sequence; Journey 2 and optional Extras remain separate. End-of-session "Next" links now cross guided/core boundaries without a second course route. Source overlap is intentional **review of the same source IDs**, not cloned exercises with new IDs; progress only reflects saved genuine attempts (not mastery or fluent understanding). Each chapter shows real attempted progress and objective matching accuracy only if an actual quiz answer exists.

The 74-word-form first-use inventory currently covers only 16 guided groups and must be extended to the 19 core Journey 1 lessons before claiming zero gaps. No hard 80%-completion gate or fabricated teaching source should be introduced.
